## 2.制作硬盘的主引导扇区

### 汇编代码 (new1.asm )

硬盘的引导扇区默认是**512**字节，因此除了汇编代码之外需要用0填充剩下的空间(汇编二进制代码可以通过软件查看大小)，并且系统引导扇区由0x55 和 0xAA结尾

```assembly
mov ax,0x30
mov dx,0xc0
add ax,dx   #汇编代码8字节

TIMES 502 db 0 # 502字节的0填充

DB 0x55  
db 0xAA # 2字节的结尾
```

### 编译

```
nasm -f bin new1.asm  -o new.bin
```

### 检查格式

使用工具检查填充之后的 512字节的汇编二进制代码(new.bin)，前面是机器指令，最后是扇区结尾

## 4.启动调试

配置好了虚拟硬盘，点击start 启动成功

![image-20231114155112689]({{ "/assets/x86assemb/assembly-01/image-20260831174658007.png" | absolute_url }})



```
Next at t=0 
```



代表虚拟机时钟

```
(0) [0x0000fffffff0] f000:fff0 (unk. ctxt): jmpf 0xf000:e05b          ; ea5be000f0
```

f000:fff0 代表cs和ip，段地址和偏移地址，

jmpf 0xf000:e05b 是下一条执行的指令

ea5be000f0 十六进制的执行代码

### 调试命令

```
sreg 段寄存器
r   通用寄存器
s 单步执行指令
b 断点
c 持续执行 直到断点停止
q 退出虚拟机
```

### 查看结果

断点到0x7c00代码位置

> 硬盘的第一个扇区是0面0道1扇区，或者说是0头0柱1扇区，这个扇区 称为主引导扇区。如果计算机的设置是从硬盘启动的，那么，ROMBIOS将读取硬盘主引导扇区的内容，将它加载到内存地址 0x0000:0x7c00（也就是物理地址0x07C00），然后用一个jmp指令跳到 那里接着执行
